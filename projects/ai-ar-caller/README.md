# Triod AI AR Caller — Conversational RCM Automation

**Status:** Working local scenario and QA prototype, not a deployed live payer-calling agent.

This project explores the logic for handling U.S. healthcare payer follow-ups and generating useful action notes from structured interactions.

## Local prototype capabilities
- Claim scenarios: paid, pending, denied, corrected and appealed
- Validate essential scenario-specific facts
- Avoid repeating known or previously requested information
- Flag missing documentation and next-action requirements
- Synthetic call evaluation and comparison examples

## Planned integrations (not yet live)
Whisper STT, telephony/IVR navigation, TTS, payer portal connectors, interruptibility and deployment controls.

The demonstration does not place real phone calls or handle real patient information. Full local example source and test suite are in the prepared portfolio archive.
