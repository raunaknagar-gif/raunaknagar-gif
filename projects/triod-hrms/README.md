# People OS / Triod HRMS — Prototype

**Status:** Local development prototype, not a deployed payroll system.

Project for managing employees, roles, payroll calculations and human resources processes. The prepared local source demo uses Python, SQLite and a lightweight web interface.

Planned modules include employee records, salary calculation, payslip generation, onboarding and employee document workflows.

All public examples should use invented/synthetic employee information, never actual bank account, government ID, or salary details.

**Full local project source:** available in the prepared project archive and may be migrated to its own repository.
