# Triod Health Care — Website Concept

**Status:** Editable portfolio prototype, not an export of the live production website.

A responsive frontend concept for Triod Health Care Private Limited's healthcare revenue cycle management business. Sections planned: services, AR follow-up, medical billing, denials and appeals, and contact/careers. The official domain is [triodhealth.com](https://triodhealth.com).

The production Hostinger site and this independent demonstration must not be confused. Source of the deployed website has not been verified as part of this portfolio.
